## Why this matters

You cannot SSH into every production failure. Logs (and later traces/metrics) are how teams reconstruct what happened.

<Callout type="mental-model">
  Prefer structured JSON logs with request/correlation ids. Log at boundaries; avoid secrets and giant payloads.
</Callout>

## Nest Logger usage

Inject or compose Logger with a context name. Coordinate with a request id middleware.

```ts
import { Injectable, Logger } from '@nestjs/common';

@Injectable()
export class TopicsService {
  private readonly logger = new Logger(TopicsService.name);

  findOne(id: string) {
    this.logger.log({ msg: 'findOne', topicId: id });
    return { id };
  }
}
```

## Common mistakes

- **Logging secrets/tokens** — Credential leak via log sinks.
- **Unstructured string concatenation only** — Hard to query in log platforms.
- **Log volume without sampling** — Cost explosion; drown signal.
