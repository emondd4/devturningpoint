## Why this matters

Go emphasizes simplicity, static binaries, and straightforward concurrency. Many cloud/DevOps APIs use it. This is a map for Nest learners exploring an alternative path—not a full Go curriculum.

<Callout type="mental-model">
  goroutines + channels are the concurrency story (different from Node's event loop). net/http is in the standard library. You often write fewer framework layers—and more explicit code.
</Callout>

## Orientation checklist

Learn tours of types, interfaces, goroutines; then build a tiny net/http JSON API.

```ts
export const nodeVsGo = {
  concurrency: {
    node: 'event loop + worker threads',
    go: 'goroutines scheduled on OS threads (simplified mental model)',
  },
  distribution: {
    node: 'node_modules + runtime',
    go: 'often a single static binary',
  },
} as const;
```

## Common mistakes

- **Expecting Nest-like DI everywhere** — Go culture is often more explicit/manual.
- **Ignoring error handling style** — err returns are part of the design.
- **Skipping the tour** — Syntax/idioms matter before frameworks.
