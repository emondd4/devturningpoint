## Why this matters

Many enterprises standardize on the JVM. If job markets or teammates use Spring, you should recognize the counterparts to Nest concepts—without abandoning fundamentals.

<Callout type="mental-model">
  Spring Boot ≈ batteries-included runtime. Spring MVC controllers ≈ Nest controllers. Spring DI ≈ Nest providers. JPA/Hibernate ≈ ORM layer. This topic is orientation, not a full Java career track.
</Callout>

## Concept mapping

Transfer HTTP/SQL/auth knowledge; relearn framework vocabulary.

```ts
export const nestToSpring: Record<string, string> = {
  Module: 'Configuration / @SpringBootApplication boundaries',
  Controller: '@RestController',
  Injectable: '@Service / @Component',
  Guard: 'HandlerInterceptor / Security filters',
  Pipe: 'Validation + HandlerMethodArgumentResolver',
};
```

## Common mistakes

- **Assuming Nest and Spring are identical** — Similar ideas; different runtime and ecosystem.
- **Skipping HTTP/SQL fundamentals** — Framework hopping without foundations fails.
- **Treating this overview as mastery** — Production Spring needs dedicated depth.
