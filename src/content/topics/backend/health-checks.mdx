## Why this matters

Load balancers need a signal. Without health endpoints, bad deploys keep receiving traffic or get flapped incorrectly.

<Callout type="mental-model">
  Liveness: process should be restarted if dead. Readiness: dependencies ready to accept work (DB, migrations). Do not make liveness fail on downstream blips casually—or you thrash restarts.
</Callout>

## Terminus-style checks

Expose separate live/ready endpoints with appropriate checks (Nest Terminus is a common recipe).

```ts
export type HealthStatus = {
  status: 'ok' | 'degraded' | 'down';
  details?: Record<string, string>;
};

export async function readiness(
  checkDb: () => Promise<boolean>,
): Promise<HealthStatus> {
  const db = await checkDb();
  return db
    ? { status: 'ok' }
    : { status: 'down', details: { db: 'unreachable' } };
}
```

## Common mistakes

- **Heavy dependency checks on liveness** — Cascading restarts during DB blips.
- **No readiness during migrations** — Traffic hits half-migrated schema.
- **Unauthenticated deep health exposing internals** — Info leak—keep public details minimal.
