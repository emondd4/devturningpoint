## Why queues exist

HTTP requests need fast responses. Email, image processing, and settlement retries belong in workers with retry/backoff/dead-letter policies.

## Mental model

Producer enqueues a message → broker stores it → consumer processes → ack/fail. At-least-once delivery means handlers should be idempotent.
