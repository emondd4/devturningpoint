## Why this matters

Frontend and partners need a reliable contract. Hand-written docs drift; OpenAPI generated from code keeps examples honest.

<Callout type="mental-model">
  Decorate DTOs/controllers; SwaggerModule builds a document you can serve as Swagger UI or export as JSON/YAML.
</Callout>

## Bootstrap sketch

Keep docs non-public in production or protect them. Align DTO validation with documented schemas.

```ts
import { DocumentBuilder, SwaggerModule } from '@nestjs/swagger';
import type { INestApplication } from '@nestjs/common';

export function setupOpenApi(app: INestApplication) {
  const config = new DocumentBuilder()
    .setTitle('Dev Turning Point API')
    .setVersion('1.0')
    .addBearerAuth()
    .build();
  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('docs', app, document);
}
```

A stale Swagger UI is worse than none—generate or validate OpenAPI in CI and treat the contract as a product surface.

## Common mistakes

- **Docs enabled anonymously in prod** — Recon surface for attackers.
- **Documenting happy path only** — Clients mishandle 4xx/5xx.
- **DTO drift from validators** — Lies in the contract.
