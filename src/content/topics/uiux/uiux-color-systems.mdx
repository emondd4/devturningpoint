## Why a color system

Random hex picks don’t scale. Products need roles: background, surface, text, brand, danger, success, warning, focus.

## Mental model

<Callout type="mental-model">
  Start from contrast requirements (WCAG). Build a neutral scale plus brand accents. Map semantics so destructive always means the same role.
</Callout>

## Practice

- Check text contrast on surfaces.
- Don’t convey status by color alone—pair with icon/text.
- Test light and dark if you support both.

## Common mistakes

- **Low-contrast gray text** — Fails readability.
- **Brand color on every element** — No hierarchy.
- **Ignoring color blindness** — Red/green-only status.

## Interview angle

<Callout type="interview">
  How do you choose error and success colors that stay accessible on light and dark themes?
</Callout>

## Practice checklist

- [ ] Define semantic color roles.
- [ ] Run contrast checks on body and buttons.
- [ ] Document do/don’t swatches in Figma.
