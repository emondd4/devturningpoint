## Why flows first

Jumping to pixels hides missing steps: OTP failures, permission denials, and back-button traps.

## Mental model

<Callout type="mental-model">
  A flow is a graph: entry → steps → decisions → success/failure exits. Annotate data needed and system feedback at each node.
</Callout>

## Tips

- Start from a user goal.
- Include alternate and exception paths.
- Align with acceptance criteria.

## Common mistakes

- **Happy path only**.
- **Flows without copy ownership**.
- **Over-detailed flows too early**.

## Interview angle

<Callout type="interview">
  Draw the flow for forgot password including expired token and rate limiting.
</Callout>

## Practice checklist

- [ ] Flow one critical journey with exceptions.
- [ ] Mark where errors appear.
- [ ] Review with eng + QA.
