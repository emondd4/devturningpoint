## Why spacing systems

Uneven gaps make UI feel accidental. A 4/8-point scale and clear columns create calm layouts.

## Mental model

<Callout type="mental-model">
  Space is hierarchy: tighter groups related items; larger gaps separate sections. Grids keep multi-breakpoint layouts predictable.
</Callout>

## Tips

- Stick to a spacing scale (4, 8, 12, 16, 24, 32…).
- Align to columns on web; respect safe areas on mobile.

## Common mistakes

- **Optical alignment ignored** — Icons look off.
- **Too many unique gaps** — No rhythm.
- **Zero margin edge-to-edge text** — Fatigue.

## Interview angle

<Callout type="interview">
  How would you set spacing tokens for a dense admin table vs a marketing page?
</Callout>

## Practice checklist

- [ ] Apply an 8pt scale to one screen.
- [ ] Set up a 12-column grid in Figma.
- [ ] Fix three inconsistent gaps.
