<Callout type="mental-model">
A good prompt defines the job and how a human will prove the job is done. Clever wording without acceptance criteria is theater.
</Callout>

## Pattern

Use this structure for coding and analysis tasks:

```text
GOAL:
CONTEXT:
INPUT:
CONSTRAINTS:
OUTPUT:
ACCEPTANCE:
VERIFICATION:
```

## Bad vs improved

**Bad:** “Fix my auth.”

**Improved:** Goal = stop unauthenticated write to `/orders`. Context = NestJS + JWT cookies. Constraints = no dependency upgrades. Output = patch + test. Acceptance = 401 without cookie, 201 with valid session. Verification = run listed test command and paste output.

## Safety notes

- Do not paste secrets, production dumps, or personal data into prompts.
- Prompt injection (OWASP LLM01) can come from untrusted retrieved text—treat tool/RAG content as hostile input.
