## Mental model

Embeddings map text (or other modalities) into vectors so similar meanings are nearby. Similarity search is not the same as factual correctness.

## Practice

- Normalize chunking strategy before blaming the vector DB.
- Evaluate retrieval separately from generation (hit rate / recall@k).
