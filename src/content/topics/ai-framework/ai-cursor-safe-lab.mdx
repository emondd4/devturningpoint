## Required workflow

1. Inspect repository structure and manifests.
2. Map architecture and trust boundaries.
3. Define requirement + non-goals.
4. Create a plan (no code yet).
5. Implement one small slice.
6. Run tests/lint/typecheck yourself.
7. Review the diff for scope and invented deps.
8. Security/edge-case check (authz, injection, secrets).
9. Manual acceptance test.
10. Semantic commit with evidence.
11. Retrospective: what the agent got wrong.

Pair with project **PBL-AI-B-002** and the verify playbook at `/ai/verify`.
