## Why this matters

Free-form prose is for humans. Software needs objects. Structured outputs + validation prevent a class of production outages and injection bugs.

## Pattern

1. Define a schema (JSON Schema / Zod / Pydantic).
2. Ask the model for that shape (provider structured output or careful prompting).
3. **Validate** before use.
4. On failure: retry with repair prompt or escalate to a human—do not silently coerce.

## Practical checks

- Reject unknown fields if your domain is strict.
- Separate raw model text from validated objects in logs.
- Test with deliberately malformed outputs.
