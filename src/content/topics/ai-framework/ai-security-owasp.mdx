## Why this matters

LLM apps fail differently than classic CRUD: attackers poison context, models emit unsafe code, and tools execute too much.

## Themes to know (OWASP GenAI LLM Top 10)

- **Prompt injection** — Hostile content overrides system intent.
- **Improper output handling** — Trusting model text as code, SQL, or HTML.
- **Excessive agency** — Tools too powerful; missing confirmation.
- **Sensitive information disclosure** — Secrets in prompts, logs, or training leakage risks.
- **Supply chain** — Hallucinated packages, unvetted MCP servers, model provenance.

Always read the current OWASP GenAI list—labels evolve.

## Practical checks

- Treat retrieved docs and tool outputs as hostile.
- Fail closed on structured outputs.
- Allowlist tools; dry-run destructive actions.
- Never paste production secrets into prompts.
