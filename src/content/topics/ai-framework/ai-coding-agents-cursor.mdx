## What Cursor customizes (current docs)

Research dated **2026-09-16** against official Cursor documentation:

1. **AGENTS.md** — plain Markdown agent instructions at repo root (and nested directories).
2. **Project Rules** — `.cursor/rules/*.mdc` with frontmatter (`description`, `globs`, `alwaysApply`).
3. **Skills** — `SKILL.md` under `.cursor/skills/` or `.agents/skills/` for reusable workflows.
4. **MCP** — connect external tools/data via `.cursor/mcp.json` (or user-level config). Prefer least privilege; approve tool use consciously.

## Safe change workflow

1. Inspect the repository and map architecture.
2. Write a bounded requirement and non-goals.
3. Ask the agent for a plan only.
4. Implement **one** milestone/slice.
5. Run formatter/lint/typecheck/tests yourself.
6. Review the diff for unrelated refactors and invented packages.
7. Check authz, validation, and secret handling.
8. Commit with a semantic message after evidence exists.

## MCP caution

MCP expands agency (OWASP excessive agency / tool risks). Only enable servers you trust; avoid broad shell or production database tools in day-to-day coding.
