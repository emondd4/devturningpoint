## Why realtime is integration-heavy

Auth, sticky sessions, reconnects, and fan-out make realtime a system design problem—not a socket snippet.

## Mental model

<Callout type="mental-model">
  Choose SSE for server→client streams; WebSockets for bidirectional. Authenticate the upgrade. Design reconnect/backoff and idempotent event payloads.
</Callout>

## Common mistakes

- **No auth on the socket handshake**.
- **Assuming one server process forever** — need pub/sub for scale.
- **Huge payloads over the socket**.

## Interview angle

<Callout type="interview">
  How would you push “topic updated” events to online learners?
</Callout>

## Practice checklist

- [ ] Pick SSE vs WebSocket for one use case.
- [ ] Document reconnect behavior.
- [ ] Sketch Redis pub/sub with two Nest instances.
