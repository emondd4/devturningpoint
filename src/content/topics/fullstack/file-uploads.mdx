## Why file pipelines are special

Files stress authz, size limits, content-type sniffing, storage costs, and malware risk.

## Mental model

<Callout type="mental-model">
  Prefer direct-to-object-storage uploads with short-lived signed URLs when possible. Validate type/size server-side. Store metadata in Postgres; blobs in object storage.
</Callout>

## Common mistakes

- **Accepting any Content-Type by trust**.
- **Storing uploads on the API disk in production**.
- **Public buckets with guessable keys**.

## Interview angle

<Callout type="interview">
  Design avatar upload for Next + Nest + S3-compatible storage.
</Callout>

## Practice checklist

- [ ] Write size/type validation rules.
- [ ] Sketch signed URL sequence.
- [ ] Plan orphan cleanup for failed uploads.
