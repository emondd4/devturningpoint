## Why boundaries matter

Full-stack bugs often live in the seams: duplicated validation, leaking internal errors, or unclear ownership of auth and caching.

## Mental model

<Callout type="mental-model">
  Treat each hop as a contract: Browser → Next (UI/BFF) → Nest (domain) → DB. Define who validates what, which status codes mean what, and which layer is source of truth.
</Callout>

## Next + Nest pattern

- Prefer Nest for domain rules and persistence.
- Use Next Route Handlers/Server Actions carefully—avoid duplicating business logic.
- Map domain errors to stable HTTP problem shapes for the UI.

## Common mistakes

- **Business logic only in React** — Mobile/other clients diverge.
- **Leaking stack traces to the browser**.
- **Chatty UI→DB coupling**.

## Interview angle

<Callout type="interview">
  Draw sequence diagrams for “load topic” and “submit form” across Next and Nest.
</Callout>

## Practice checklist

- [ ] List contracts between Next and Nest for one feature.
- [ ] Define error mapping for 401/403/409/422.
- [ ] Identify one validation that must stay server-side.
