## Why full-stack E2E

Unit tests miss contract breaks between UI and API. A few critical journeys catch integration regressions.

## Mental model

<Callout type="mental-model">
  Run against a compose stack or ephemeral environment. Seed data intentionally. Prefer user-facing locators. Keep the suite small and high-signal.
</Callout>

## Common mistakes

- **E2E-only strategy**.
- **Shared mutable users across parallel tests**.
- **No traces on failure**.

## Interview angle

<Callout type="interview">
  Design E2E for signup → verify email → first project create.
</Callout>

## Practice checklist

- [ ] Write one Playwright journey against local compose.
- [ ] Isolate test users.
- [ ] Wire the job into CI artifacts.
