## Why `tail -f` does not scale past one box

Incidents span many hosts and containers. You need structured events, shippers, searchable storage, and retention that matches compliance and cost.

## Mental model

<Callout type="mental-model">
  Emit JSON (or consistent key=value) → ship via agent/collector → index/store → query during incidents. Correlate with metrics and traces via request ids.
</Callout>

```bash
# App emits structured logs to stdout; container runtime collects them
node -e 'console.log(JSON.stringify({level:"info",msg:"order_created",orderId:"o_1",traceId:"abc"}))'
journalctl -u topics-api -o json-pretty | head
```

Choose stacks deliberately (ELK/EFK, Loki+Grafana, cloud logging). Cost is dominated by volume and high-cardinality fields.

## Common mistakes

- **Logging secrets/PII** — Redact at source.
- **Unstructured multi-line dumps only** — Hard to query.
- **Infinite retention “just in case”** — Budget hot vs cold storage.

## Interview angle

<Callout type="interview">
  Design a minimal logging path from a Node container to a searchable backend.
</Callout>

## Practice checklist

- [ ] Convert one `console.log` string into JSON fields.
- [ ] Query journald for a unit since a timestamp.
- [ ] Sketch retention tiers for prod logs.
