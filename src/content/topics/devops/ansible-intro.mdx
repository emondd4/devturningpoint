## Why manual SSH drifts every host

Golden images help, but package versions and config files still diverge. Ansible applies declared state over SSH without installing agents on every box.

## Mental model

<Callout type="mental-model">
  Inventory lists hosts. Playbooks list plays → tasks. Modules should be idempotent: re-running converges to the same desired state.
</Callout>

```yaml
- name: Ensure nginx present
  hosts: web
  become: true
  tasks:
    - name: Install nginx
      ansible.builtin.package:
        name: nginx
        state: present
    - name: Enable and start nginx
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true
```

Use Terraform/OpenTofu for cloud resources; Ansible often shines for OS config and app bootstrap on VMs.

## Common mistakes

- **Shell tasks for everything** — Prefer modules for idempotency.
- **No inventory groups** — Untargeted plays are dangerous.
- **Secrets in playbooks** — Use Ansible Vault or external secret injection.

## Interview angle

## Practice checklist

- [ ] Write a playbook that installs a package and starts a service.
- [ ] Run with `--check` first.
- [ ] Organize hosts into inventory groups.
