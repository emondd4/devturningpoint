## Why explore

Scripted cases encode known risks. Exploration invents new questions while you learn the product.

## Mental model

<Callout type="mental-model">
  Time-box a charter (“Explore password reset as a user with expired token for 45 minutes”). Note oracles: expectations from specs, similar products, and common sense. Debrief findings into bugs and new regression candidates.
</Callout>

## Techniques

- Tours (feature, claims, emotion, money).
- Persona-based exploration.
- Pair testing with a developer for fast fixes.

## Common mistakes

- **Wandering without a charter** — Hard to report coverage.
- **No notes** — Insights evaporate.
- **Treating exploration as anti-automation** — Both reinforce each other.

## Interview angle

<Callout type="interview">
  Design a 60-minute exploratory charter for a wallet top-up flow.
</Callout>

## Practice checklist

- [ ] Run one charter and write a debrief.
- [ ] Convert two findings into automation candidates.
- [ ] Share heuristics you used as oracles.
