## Decision guide

| Need | Typical choice |
|------|----------------|
| Simple flags/settings | shared_preferences |
| Tokens/secrets | flutter_secure_storage |
| Relational offline data | sqflite / drift |
| Flexible document cache | hive / isar (evaluate current ecosystem) |

Never store long-lived secrets in plain SharedPreferences.
