## Why on-device storage is not optional

Networks fail. Users expect drafts, feed caches, and auth session continuity. Local persistence is a product feature, not an optimization.

## Mental model

<Callout type="mental-model">
  **SQLite (sqflite)** shines for relational queries, joins, and partial indexes. **Hive** (and similar key-value boxes) shines for simple typed objects and fast reads without SQL. Prefer SharedPreferences only for tiny settings—not for datasets.
</Callout>

## When to pick what

| Need | Lean toward |
| --- | --- |
| Filter/sort large lists offline | sqflite / SQLite |
| Simple cache of JSON models | Hive / similar |
| Sync conflict rules | Explicit repository layer either way |

Encrypt sensitive data at rest when storing tokens or PII; never treat local DB as secure by default on rooted/jailbroken devices.

## Common mistakes

- Storing secrets in plain SharedPreferences
- Blocking UI isolate with heavy DB migrations
- No schema versioning strategy (`onUpgrade`)
