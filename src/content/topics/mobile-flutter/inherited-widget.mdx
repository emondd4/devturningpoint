## Why InheritedWidget is the framework’s secret bus

Prop-drilling theme, locale, or auth through every constructor does not scale. InheritedWidget lets descendants call `of(context)` to subscribe to an ancestor. Provider/Riverpod build on this idea.

## Mental model

<Callout type="mental-model">
  When a descendant depends on an InheritedWidget, Flutter registers that dependency. If `updateShouldNotify` says the value changed, dependents rebuild. `.of(context)` both reads and subscribes.
</Callout>

## How

### Minimal inherited model

```dart
class CartScope extends InheritedWidget {
  const CartScope({super.key, required this.count, required super.child});
  final int count;

  static CartScope of(BuildContext context) {
    final scope = context.dependOnInheritedWidgetOfExactType<CartScope>();
    assert(scope != null, 'CartScope not found');
    return scope!;
  }

  @override
  bool updateShouldNotify(CartScope old) => count != old.count;
}

// Somewhere below:
// Text('Items: ${CartScope.of(context).count}');
```

## Common mistakes

- **Calling `dependOnInheritedWidgetOfExactType` in places that should not rebuild**
- **Putting huge objects in InheritedWidget without granular selectors**
- **Forgetting updateShouldNotify semantics** — rebuild storms or stale UI
