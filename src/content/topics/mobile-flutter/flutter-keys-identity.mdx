<Callout type="mental-model">
  Widgets are configuration. Elements hold State. Keys help Flutter decide which Element to reuse when the widget list changes.
</Callout>

## Why keys exist

When children reorder (lists, tabs), Flutter needs identity—not just position—to keep the correct `State` (scroll offset, text controllers, animation controllers).

## Example

```dart
ListView(
  children: items.map((item) => TodoTile(key: ValueKey(item.id), item: item)).toList(),
);
```

## Anti-patterns

- `UniqueKey()` on every rebuild (forces remount)
- Missing keys in reorderable lists
