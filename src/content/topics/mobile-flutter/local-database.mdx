## Why local storage choice matters

Caches, drafts, and offline-first apps need durable storage. Key-value prefs are not a database. SQLite gives relational queries on device when structure and indexing matter.

## Mental model

<Callout type="mental-model">
  Use prefs for small settings; use SQLite (sqflite/drift) for collections you query/filter. Always version schemas and migrate carefully on upgrade.
</Callout>

## How

### Parameterized queries (sqflite style)

```dart
// Pseudo-structure — follow current sqflite/drift APIs in docs
Future<List<Map<String, Object?>>> openNotes(Database db) {
  return db.query(
    'notes',
    where: 'user_id = ?',
    whereArgs: ['u1'],
    orderBy: 'updated_at DESC',
  );
}
```

## Common mistakes

- **String-concatenating SQL** — injection risk even on device
- **Storing secrets in prefs in plaintext**
- **Blocking UI isolate with huge migrations**
