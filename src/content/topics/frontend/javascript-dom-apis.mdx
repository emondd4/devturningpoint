## Why this matters

Browsers expose pages as a tree of nodes. Without the DOM, JavaScript has no standard way to read or change structure, text, and attributes.

<Callout type="mental-model">
  The DOM is a live tree representing the document. Query nodes, mutate carefully, listen to events—but prefer framework-owned updates once you adopt React.
</Callout>

## Core operations

Learn querySelector, createElement, textContent vs innerHTML, and event listeners. Prefer textContent for untrusted strings; treat HTML injection APIs as XSS sinks.

```ts
const list = document.querySelector<HTMLUListElement>('#topics');
if (!list) throw new Error('Missing #topics');

const item = document.createElement('li');
item.textContent = 'FRONTEND-JS-DOM-APIS';
list.append(item);
```

## Common mistakes

- **innerHTML with user input** — XSS risk—sanitize or use textContent/Trusted Types.
- **Direct DOM edits inside React** — React may overwrite your changes on the next commit.
- **Querying before mount** — Null refs if the script runs before the node exists.

## Interview angle
