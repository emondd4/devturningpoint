## Why this matters

Users feel slow pages as abandoned sessions. Performance work without measurement wastes time; Web Vitals give a shared language for LCP/INP/CLS.

<Callout type="mental-model">
  Ship less JS (RSC boundaries, code-split), optimize LCP candidates (images/fonts), keep interactions responsive, stabilize layout.
</Callout>

## Measure then change

Use field data when available; lab tools for reproduction. Memoization is not a substitute for removing unnecessary work.

```tsx
// Example: defer non-critical client island
import dynamic from 'next/dynamic';

const Analytics = dynamic(() => import('./analytics'), {
  ssr: false,
  loading: () => null,
});

export function Shell({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <Analytics />
    </>
  );
}
```

## Common mistakes

- **Micro-memoizing everything** — Adds complexity; profile first.
- **Giant client bundles for static content** — Prefer Server Components.
- **Ignoring images/fonts** — Often dominate LCP.
