`fetch` only rejects on network failure—not on 404/500. Always check `response.ok`.

```ts
const res = await fetch('/api/orders');
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();
```

Use `AbortController` when components unmount or users navigate away.
