## Why this project matters

Subscription SaaS combines tenancy, entitlements, billing edge cases, and operability—the senior fullstack trifecta.

<Callout type="mental-model">
  Tenant boundaries first. Entitlements gate features. Billing webhooks are source of paid truth.
</Callout>

## Skills this proves

Learning outcomes map to: FULLSTACK-INTEGRATION, FULLSTACK-SSR-BOUNDARIES, FULLSTACK-E2E-TESTING, FULLSTACK-CORS-CSRF, BACKEND-QUEUES.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Tenant → members → subscription → entitlements. Billing provider stub/webhooks. Admin metrics. CI deploy to a VM/container.

Recommended tools: Next.js, NestJS, Postgres, Stripe test/fake, OpenTelemetry/logs, GitHub Actions.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Tenancy. 2) Plans/limits. 3) Billing webhook. 4) Observability. 5) CI/CD + E2E.

## Validation checkpoints

Plan limits enforced; webhook idempotent; cross-tenant blocked; pipeline deploys preview/stage.

## Common errors

Feature flags without tenant scope; trusting client plan; no webhook signature verify.

## Debugging guidance

Trace tenant+request ids; billing fixture replays.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

Isolation+entitlement+webhook e2e; load smoke optional.

## Security

Webhook verify; secret management; admin hardening.

## Performance

Per-tenant indexes; cache entitlement checks carefully.

## Accessibility

Billing/settings forms accessible.

## Deployment / handoff

GitHub Actions + container registry + release notes.
