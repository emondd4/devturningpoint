## Why this project matters

A tracker is small enough to finish yet forces real auth, data modeling, and FE/BE contracts.

<Callout type="mental-model">
  One product, two runtimes. Contracts and auth cookies/tokens dominate integration bugs.
</Callout>

## Skills this proves

Learning outcomes map to: FULLSTACK-INTEGRATION, FULLSTACK-AUTH-FLOWS, FULLSTACK-CORS-CSRF, FULLSTACK-E2E-TESTING, BACKEND-POSTGRES.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Next UI + API (Nest or Next route handlers) + Postgres. Application entities with status pipeline.

Recommended tools: Next.js, NestJS or Route Handlers, PostgreSQL, Docker Compose.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Compose stack. 2) Auth. 3) Applications CRUD. 4) Filters/dashboard. 5) E2E smoke.

## Validation checkpoints

Register/login works; CRUD persists; unauthorized blocked; env example complete.

## Common errors

CORS guesswork; tokens in localStorage by default without tradeoff note; shared .env committed.

## Debugging guidance

Network tab + API logs; reproduce with curl; check cookie flags.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

API tests + one Playwright journey optional.

## Security

httpOnly cookies preferred for web; CSRF plan if cookie sessions.

## Performance

Paginate applications; index status/date.

## Accessibility

Forms labeled; status not color-only.

## Deployment / handoff

Compose README; optional cloud DB free tier.
