## Why this project matters

Real documents are multimodal. Pipelines must preserve provenance and evaluate vision failures separately.

## Market / role relevance

Observed in Bangladesh job listings reviewed for software roles: AI feature delivery and AI-assisted engineering appear as plus skills, while verification, security judgment, and measurable quality remain baseline expectations.

## What job skills it proves

Region provenance, multimodal retrieval/QA, split eval, injection-aware PDF handling.

## Prerequisites

RAG fundamentals and evaluation basics recommended. Multimodal skill develops here.

## Architecture / approach

PDF/images → page/region extract → index → retrieve → text/vision generate with citations → modality eval.

## Recommended tools

Local vision models via Ollama when possible; otherwise capped multimodal APIs.

## Setup

1. Start with a small synthetic doc pack.
2. Prefer local vision models.
3. Cap cloud image-token spend explicitly.

## Step-by-step guidance

Milestones M01–M04. Measure OCR/layout error before blaming the LLM.

## Evaluation / security / cost / latency notes

**Eval:** split by modality.
**Security:** PDFs can carry prompt injection.
**Cost/latency:** images are expensive—cache extractions captions.

Save every item listed in frontmatter `portfolioEvidence`. Include eval scores, cost/latency notes, and security checklist outcomes.

## Retrospective

Which errors were layout vs model? Was vision worth the cost on your set?
