## Why this project matters

Prompt quality is an engineering property. This lab builds gold sets, rubrics, and cost/latency notes before product polish.

## Market / role relevance

Observed in Bangladesh job listings reviewed for software roles: AI feature delivery and AI-assisted engineering appear as plus skills, while verification, security judgment, and measurable quality remain baseline expectations.

## What job skills it proves

Verifiable prompting, structured outputs, lightweight evaluation, and honest cost reporting.

## Prerequisites

AI LLM fundamentals and prompt engineering topics—or Start Anyway knowing you will rebuild the rubric.

## Architecture / approach

Offline notebook/CLI: inputs → prompt variant → model → parser → rubric scorer → report artifacts.

## Recommended tools

Notebook + Ollama (preferred) or a capped free/paid API. Never commit API keys.

## Setup

1. Create a private working repo.
2. Prefer Ollama locally.
3. If using a paid API, set a hard spend limit and document it in COST_LATENCY.md first.

## Step-by-step guidance

Complete milestones M01–M04. Keep the gold set tiny but real; depth beats volume.

## Evaluation / security / cost / latency notes

**Eval:** rubric scores on held-out cases.
**Security:** no secrets/PII in prompts; treat model output as untrusted.
**Cost/latency:** log tokens and wall time; prefer local when quality is close.

## Portfolio evidence

Save every item listed in frontmatter `portfolioEvidence`. Include eval scores, cost/latency notes, and security checklist outcomes.

## Stretch goals

Add a regression gate that fails CI if average score drops >10%.

## Retrospective

Which failure mode did the rubric miss? Would you pay for a stronger model after seeing the numbers?
