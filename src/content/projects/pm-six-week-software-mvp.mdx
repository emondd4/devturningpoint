<Callout type="warning" title="Simulated vs real evidence">
  Practice artifacts are fine when labeled simulated. Never claim fabricated approvals, budgets, or outcomes as real results.
</Callout>

## Why this project matters

Most MVP failures are scope failures. Planning a bounded six-week MVP trains prioritization and clarity.

<Callout type="mental-model">
  Outcomes → scope cuts → backlog → risks → cadence. Non-goals are as important as goals.
</Callout>

## Skills this proves

Learning outcomes map to: PM-SDLC, PM-REQUIREMENTS, PM-AGILE, PM-ESTIMATION, PM-JIRA.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Pick a simple product idea (labeled simulated). Produce planning pack a team could start Monday.

Recommended tools: Notion/Google Docs, Jira/GitHub Projects, Spreadsheet for risks.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Charter. 2) Scope/non-goals. 3) Stories+AC. 4) Estimates+plan. 5) Risks+comms template.

## Validation checkpoints

Scope fits six weeks with explicit cuts; AC testable; risks have owners; plan has milestones.

## Common errors

Feature laundry lists; no non-goals; estimates without assumptions; fake stakeholder approvals claimed as real.

## Debugging guidance

If plan overflows, cut scope—not quality of AC.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

Peer review: could a team execute without you in the room?

## Security

Include security/privacy stories if user data exists.

## Performance

Define MVP success metrics lightly (activation/retention proxies).

## Accessibility

Include a11y acceptance for user-facing stories.

## Deployment / handoff

Planning pack in Git/Drive with changelog.

## Portfolio evidence checklist

Capture every item in frontmatter `portfolioEvidence`. Artifacts beat claims.

## Retrospective

- What was hardest?
- What failed, and how did you recover?
- How did you validate the result?
- What major trade-off did you make?
- What would you change with one more week?
- How would you scale or harden this?
- What did you deliberately not build?
- What evidence proves it works?
