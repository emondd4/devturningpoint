## Why this project matters

Every engineer lives in the terminal. Shipping a small toolbox trains argument parsing, filesystem safety, exit codes, and readable docs.

<Callout type="mental-model">
  A CLI is a contract: args in, deterministic side effects out, non-zero exits on failure, and help text that prevents foot-guns.
</Callout>

## Skills this proves

Learning outcomes map to: FOUNDATIONS-FILESYSTEMS, FOUNDATIONS-GIT, FOUNDATIONS-ERROR-HANDLING, FOUNDATIONS-DEBUGGING.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Thin command router with shared IO/utilities. Keep subcommands modular and unit-test parsers without touching disk.

Recommended tools: Python 3 or Node.js, Git, bash/zsh.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Scaffold + help. 2) JSON pretty/validate. 3) SHA-256 hash. 4) Path helpers. 5) Git summary via argv subprocess. 6) Tests + packaging.

## Validation checkpoints

Help works; invalid input exits non-zero; hash matches known fixture; JSON output stable.

## Common errors

Swallowing exceptions; path traversal; shell injection; README without install examples.

## Debugging guidance

Reproduce with fixtures; print argv at debug level; run git subprocess manually first.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

Unit-test parsers; smoke-test CLI entrypoint on fixtures; keep network out of tests.

## Security

Document symlink policy; never log secrets; prefer explicit paths.

## Performance

Stream large files for hashing; reject oversized pretty-print inputs.

## Accessibility

Clear messages, stable exit codes, optional --json machine output.

## Deployment / handoff

Local install instructions; optional GitHub Release.
