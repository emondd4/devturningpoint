## Why this project matters

Multi-tenancy mistakes leak customer data. This project forces isolation into design and tests.

<Callout type="mental-model">
  Every query is tenant-scoped. AuthN ≠ AuthZ. Guards encode policy, not controllers sprinkled with ifs.
</Callout>

## Skills this proves

Learning outcomes map to: BACKEND-AUTH, BACKEND-JWT, BACKEND-SECURITY, BACKEND-NESTJS-DI, BACKEND-TESTING.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Tenant → members/roles → projects → tasks. JWT carries sub+tenant. Row-level tenant_id with automated tests for cross-tenant access.

Recommended tools: NestJS, PostgreSQL, JWT, Passport/guards, Jest.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Auth+users. 2) Tenant model. 3) RBAC. 4) Projects/tasks. 5) Isolation test battering ram.

## Validation checkpoints

Cross-tenant reads/writes 403/404; role matrix enforced; tokens expire; tests fail if tenant filter removed.

## Common errors

Global task lists; trusting client tenant_id; JWT in localStorage guidance for SPAs without context.

## Debugging guidance

Log tenant from ALS/request context; negative tests first.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

Mandatory cross-tenant e2e cases; guard unit tests.

## Security

OWASP API top risks awareness; rotate secrets; bcrypt passwords.
