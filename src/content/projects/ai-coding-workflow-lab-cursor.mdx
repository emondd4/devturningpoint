## Why this project matters

Coding agents change throughput, not accountability. This lab builds the habit: plan → bounded agent work → human verification.

## Market / role relevance

Observed in Bangladesh job listings reviewed for software roles: AI-assisted coding familiarity appears as a plus, while verification and Git hygiene remain baseline expectations—not a substitute for engineering judgment.

## What job skills it proves

Prompt structure, Cursor Rules/Skills/MCP awareness, diff review, and evidence-based verification.

## Prerequisites

Complete AI LLM fundamentals, prompt engineering, and the Cursor agents topic first—or Start Anyway knowing you will rework.

## Architecture / approach

Treat the agent as a junior pair programmer with tools. Your PROCESS_PLAN and verification files are the system of record.

## Recommended tools

Cursor, Git, and the language toolchain of the sample repository.

## Setup

1. Install Cursor and open a practice repository.
2. Ensure you can run that repo's tests locally without AI.
3. Create a working branch for the lab.

## Step-by-step guidance

Follow milestones M01–M04 in order. Use prompt recipes `PROMPT-REPO-DISCOVERY` and `PROMPT-IMPLEMENT-ONE-MILESTONE`.

## Validation / testing / security

Run real commands. Review for hallucinated dependencies, secret leakage, and overbroad refactors (OWASP supply chain / improper output handling / excessive agency themes).

## Portfolio evidence

Save every item listed in frontmatter `portfolioEvidence`.

## Stretch goals

Add a project Skill for “verify before claim tests passed.”

## Retrospective

Hardest agent mistake? What evidence caught it? What will you forbid in rules next time?
