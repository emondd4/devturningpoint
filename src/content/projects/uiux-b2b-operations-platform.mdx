## Why this project matters

B2B ops tools are where UX maturity shows—density, permissions, and IA under real work constraints.

<Callout type="mental-model">
  Roles define worlds. IA reduces hunting. Tables need progressive disclosure. Systems need governance.
</Callout>

## Skills this proves

Learning outcomes map to: UIUX-DESIGN-SYSTEMS, UIUX-WIREFRAMING, UIUX-PROTOTYPING, UIUX-A11Y, UIUX-UX-RESEARCH.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Choose domain (inventory ops, support ops, logistics). Deliver IA, role matrix, key workflows, dense screens, system extensions, case study.

Recommended tools: Figma, IA maps, Table patterns, Role matrix, Usability scripts.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Domain+roles. 2) IA. 3) Core workflows. 4) Table/filter patterns. 5) Governance+usability validation.

## Validation checkpoints

Role paths differ correctly; IA findability tested; tables handle empty/loading/error; governance documented.

## Common errors

Consumer-app aesthetics on ops tools; ignoring permissions; unusable wide tables.

## Debugging guidance

Watch task times; if users hunt, fix IA before colors.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

Tree test/findability; task-based usability with ops-like scenarios (labeled if simulated).

## Security

Permission UX clarity; avoid exposing hidden admin via UI alone.

## Performance

Perceived performance via skeletons and pagination patterns.

## Accessibility

Keyboard table interactions; don't rely on color for status.

## Deployment / handoff

Advanced case study with decision log.

## Portfolio evidence checklist

Capture every item in frontmatter `portfolioEvidence`. Artifacts beat claims.
