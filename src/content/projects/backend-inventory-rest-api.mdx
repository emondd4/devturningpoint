## Why this project matters

Inventory CRUD is the classic backend proving ground for REST, validation, and DB modeling.

<Callout type="mental-model">
  Resources + representations. Validate at the edge. Persist with constraints, not only app checks.
</Callout>

## Skills this proves

Learning outcomes map to: BACKEND-REST, BACKEND-NESTJS, BACKEND-VALIDATION, BACKEND-POSTGRES, BACKEND-TESTING.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Modules: products, stock movements. DTOs + pipes. Postgres via ORM. Compose for local DB.

Recommended tools: NestJS, PostgreSQL, Prisma/TypeORM, Jest, Docker Compose.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Nest scaffold+compose. 2) Product CRUD. 3) Stock adjust. 4) Pagination/filtering. 5) OpenAPI+tests.

## Validation checkpoints

Invalid DTOs 400; stock never negative if constrained; OpenAPI matches routes; tests cover happy+sad.

## Common errors

Anemic validation; N+1 lists; leaking ORM entities as API types.

## Debugging guidance

SQL logging; supertest failures; constrain DB to catch app bugs.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>
