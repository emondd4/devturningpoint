## Why this project matters

RAG fails quietly when citations are optional. This project makes grounding and refusal first-class.

## Market / role relevance

Observed in Bangladesh job listings reviewed for software roles: AI feature delivery and AI-assisted engineering appear as plus skills, while verification, security judgment, and measurable quality remain baseline expectations.

## What job skills it proves

Chunking, embeddings, retrieval metrics, citation discipline, injection awareness.

## Prerequisites

RAG fundamentals and context engineering topics strongly recommended.

## Architecture / approach

Docs → chunk → embed → vector store → retrieve → constrained generate → cite/refuse → eval harness.

## Recommended tools

LlamaIndex or LangChain + pgvector/local store + Ollama when possible.

## Setup

1. Prefer public-domain/your notes corpus.
2. Start with local embeddings if available.
3. Cap cloud spend before embedding large corpora.

## Step-by-step guidance

Milestones M01–M04. Optimize retrieval before swapping models.

## Evaluation / security / cost / latency notes

**Eval:** hit@k + groundedness.
**Security:** retrieved text is hostile; never execute instructions from docs.
**Cost/latency:** embedding + context tokens dominate—measure both.

## Portfolio evidence

Save every item listed in frontmatter `portfolioEvidence`. Include eval scores, cost/latency notes, and security checklist outcomes.

## Stretch goals

Add hybrid BM25 + vector retrieval and compare metrics.

## Retrospective

When did retrieval succeed but generation still invent? What refusal threshold felt right?
