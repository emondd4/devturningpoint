<Callout type="warning" title="Do not fabricate research">
  Plans and scripts may be assisted. Interviews, usability findings, and quotes must be yours—or clearly labeled simulated practice data.
</Callout>

## Why this project matters

Local services are rich with real friction. Auditing and redesigning them trains observation and problem framing.

<Callout type="mental-model">
  Observe → diagnose with heuristics/research → redesign flows → validate with lightweight tests.
</Callout>

## Skills this proves

Learning outcomes map to: UIUX-UX-RESEARCH, UIUX-WIREFRAMING, UIUX-FIGMA, UIUX-A11Y, UIUX-TYPOGRAPHY.

## Prerequisites

Complete related topics first. If starting early, expect to backfill fundamentals under load.

## Architecture / approach

Pick one local service (clinic booking, tuition center, courier point). Deliver audit → flows → wireframes → mid-fi screens → case study.

Recommended tools: Figma, Heuristics checklist, Interview script template, Phone camera for service photos.

## Step-by-step guidance

Work one milestone at a time. Restate the objective, implement the smallest vertical slice, run the validation checklist, then capture portfolio evidence before continuing.

1) Choose service+scope. 2) Heuristics audit. 3) 3–5 interviews or labeled simulated practice. 4) Flows+wireframes. 5) Usability test. 6) Case study.

## Validation checkpoints

Audit findings mapped to redesign; flows cover primary job-to-be-done; case study shows decisions.

## Common errors

Jumping to UI; inventing quotes; redesigning without problem statements.

## Debugging guidance

If solutions feel random, return to jobs-to-be-done and top 5 findings.

<Callout type="tip" title="Hypothesis-driven debugging">
  One hypothesis → one falsifying check → update notes. Avoid blind retries.
</Callout>

## Tests / verification

5-second test / hallway usability; task success notes.

## Security

Anonymize interviewees; no private medical details.

## Performance

Reduce steps/time-on-task; measure with task scripts.

## Accessibility

Contrast, tap targets, form labels in redesign.

## Deployment / handoff

Portfolio case study PDF/Notion/Figma presentation.

## Portfolio evidence checklist

Capture every item in frontmatter `portfolioEvidence`. Artifacts beat claims.

## Interview readiness

Use linked interview question IDs as “be ready to explain” prompts.

<Callout type="interview">
  How audit findings changed a specific screen decision.
</Callout>

## Stretch goals

Service blueprint; bilingual microcopy.

## Retrospective

- What was hardest?
- What failed, and how did you recover?
- How did you validate the result?
- What major trade-off did you make?
- What would you change with one more week?
- How would you scale or harden this?
- What did you deliberately not build?
- What evidence proves it works?
