## Why this project matters

Production agents need durable state, interrupts, and narrow tool surfaces—LangGraph + MCP make those concerns explicit.

## Market / role relevance

Observed in Bangladesh job listings reviewed for software roles: AI feature delivery and AI-assisted engineering appear as plus skills, while verification, security judgment, and measurable quality remain baseline expectations.

## What job skills it proves

Graph design, MCP least privilege, checkpoints, human approval, scenario eval.

## Prerequisites

Agents overview, MCP intro, tool calling, and AI security topics.

## Architecture / approach

LangGraph state machine ↔ model nodes ↔ MCP tool nodes ↔ checkpoint store ↔ human interrupt channel.

## Recommended tools

LangGraph, MCP servers, SQLite/Postgres checkpoints, local/capped LLM.

## Setup

1. Follow LangGraph docs for a minimal graph.
2. Run MCP servers with least privilege.
3. Cap model spend before long loops.

## Step-by-step guidance

Milestones M01–M04. Prove resume and approval before adding features.

## Evaluation / security / cost / latency notes

**Eval:** multi-step success + approval correctness.
**Security:** MCP scopes, injection via tool output.
**Cost/latency:** step budget and token ceilings.
