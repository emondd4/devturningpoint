## Why this project matters

Copilot SaaS value collapses without isolation, budgets, and audits. This project forces those production concerns.

## Market / role relevance

Observed in Bangladesh job listings reviewed for software roles: AI feature delivery and AI-assisted engineering appear as plus skills, while verification, security judgment, and measurable quality remain baseline expectations.

## What job skills it proves

Multi-tenant RAG, isolation testing, budgets, auditability, tool allowlists, release gates.

## Prerequisites

RAG, security, tool calling, and evaluation topics; prior intermediate AI projects recommended.

## Architecture / approach

Auth → tenant context → per-tenant retrieval/tools → metered LLM → audit log → eval gates.

## Recommended tools

Your web stack + Postgres/pgvector + local/capped models.

## Setup

1. Start with two fake tenants and synthetic docs.
2. Prefer local models to control cost.
3. Set explicit cloud spend caps if used.

## Step-by-step guidance

Milestones M01–M04. Isolation tests before UI polish.

## Evaluation / security / cost / latency notes

**Eval:** quality + security cases per tenant.
**Security:** cross-tenant retrieval tests are mandatory.
**Cost/latency:** per-tenant budgets and p95 latency.

## Portfolio evidence

Save every item listed in frontmatter `portfolioEvidence`. Include eval scores, cost/latency notes, and security checklist outcomes.

## Stretch goals

Add SSO and region-aware data residency notes.

## Retrospective

What almost leaked across tenants? Which budget policy felt fair?
